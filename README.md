# Polymarket Data Extractor
A lightweight Python/Colab-ready tool for extracting **Polymarket markets, tags, and trade metrics** using both **Gamma API** and **Data API**.

## ✨ Features
- Search tags by keyword (`/tags`)
- Download all markets (open + closed) for selected tag IDs
- Retrieve trades for each market via Data API
- Compute number of unique traders, total trades, first/last trade timestamps
- Export per-tag `.jsonl` + `.csv` and combined CSV
